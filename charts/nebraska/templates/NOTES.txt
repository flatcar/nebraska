WARNING: the PostgreSQL superuser password is "changeIt", the fixed default
         that chart 3.0.0 shipped. 4.0.0 generates a random one on a new install,
         but keeps the password an existing database already uses, so this was
         carried over from 3.0.0.

  Anything on the pod network that knows this default has full control of the
  database, including command execution inside its container. There is no
  NetworkPolicy restricting access to port 5432.

  Setting postgresql.auth.postgresPassword will not change it, because the
  chart keeps the password stored in the Secret. To change it, update both
  PostgreSQL and the Secret, then restart Nebraska:

    kubectl exec -n {{ .Release.Namespace }} {{ include "nebraska.postgresql.fullname" . }}-0 -- \
      psql -U {{ .Values.postgresql.auth.username }} -d {{ .Values.postgresql.auth.database }} \
      -c "ALTER USER {{ .Values.postgresql.auth.username }} PASSWORD '<new-password>'"
    kubectl patch secret {{ include "nebraska.postgresql.fullname" . }} -n {{ .Release.Namespace }} \
      -p '{"stringData":{"{{ .Values.postgresql.auth.secretKeys.adminPasswordKey }}":"<new-password>"}}'
    kubectl rollout restart deployment/{{ include "nebraska.fullname" . }} -n {{ .Release.Namespace }}

  If your values file sets postgresPassword: changeIt, remove that line too.

{{ end -}}
