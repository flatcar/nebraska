{{- /* Check the stored Secret too: a default 3.0.x install never set the value
       in its values file, yet its Secret holds changeIt, and a persistent
       upgrade keeps it (templates/postgresql.yaml). lookup sees the Secret as
       it was before this upgrade. */ -}}
{{- $pwSecret := (lookup "v1" "Secret" .Release.Namespace (include "nebraska.postgresql.fullname" .)) | default dict }}
{{- $storedPw := index ($pwSecret.data | default dict) .Values.postgresql.auth.secretKeys.adminPasswordKey | default "" | b64dec }}
{{- /* Same condition as the rotation in templates/postgresql.yaml. */ -}}
{{- $rotated := and (eq $storedPw "changeIt") (not .Values.postgresql.auth.postgresPassword) (not .Values.postgresql.primary.persistence.enabled) (hasPrefix "postgresql-" (include "nebraska.postgresql.liveChart" .)) }}
{{- $keptStored := and (eq $storedPw "changeIt") (not $rotated) }}
{{- if and .Values.postgresql.enabled (not .Values.postgresql.auth.existingSecret) (or (eq (.Values.postgresql.auth.postgresPassword | toString) "changeIt") $keptStored) -}}
WARNING: the PostgreSQL superuser password is "changeIt", the old default of
  chart 3.0.x. Anyone who can reach the database can use it. Changing
  postgresql.auth.postgresPassword does not change it. To change it, run:

    kubectl exec -n {{ .Release.Namespace }} {{ include "nebraska.postgresql.fullname" . }}-0 -- \
      psql -U {{ .Values.postgresql.auth.username }} -d {{ .Values.postgresql.auth.database }} \
      -c "ALTER USER {{ .Values.postgresql.auth.username }} PASSWORD '<new-password>'"
    kubectl patch secret {{ include "nebraska.postgresql.fullname" . }} -n {{ .Release.Namespace }} \
      -p '{"stringData":{"{{ .Values.postgresql.auth.secretKeys.adminPasswordKey }}":"<new-password>"}}'
    kubectl rollout restart deployment/{{ include "nebraska.fullname" . }} -n {{ .Release.Namespace }}

  Also remove postgresPassword: changeIt from your values file, if it is there.

{{ end -}}

PASSWORD CHANGED: the old default password "changeIt" was replaced with a
